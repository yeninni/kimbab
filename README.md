# 김밥 MBTI

2026 김천김밥축제에 쓰려고 만든 성격 테스트입니다. 12개 질문에 답하면 16가지 김밥 유형 중 하나가 나옵니다. 결과 화면에는 유형 설명, 축제에서의 모습, 잘 맞는 유형, 추천 활동, 해시태그가 함께 나옵니다.

- 사이트: https://yeninni.github.io/kimbab/gimbap_mbti.html
- 질문과 결과 화면: `gimbap_mbti.html`
- 유형 데이터: `mbti-data.json`. ESTJ 정통 참치김밥부터 INFP 단호박 고구마 김밥까지 16종입니다.

## 실행

빌드나 서버 없이 `gimbap_mbti.html`을 브라우저에서 열면 바로 됩니다. 폰트와 마스코트 이미지는 `assets/`에 있습니다.

## 배포

GitHub Pages의 `apply` 브랜치로 배포합니다. `apply` 브랜치의 `index.html`은 `gimbap_mbti.html`로 넘깁니다.
